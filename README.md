# Jazz Language Atlas

A professional jazz language knowledge platform covering harmony, rhythm, improvisation, voicing, reharmonization, ear training, performance language, technology, analysis, and creative philosophy.

## Features

- 32 master domains
- Dynamic domain pages
- Dynamic topic pages
- Search system
- Artist studies
- Listening guides
- Interactive tools
- Chord-scale finder
- ii-V-I generator
- Target-tone generator
- Quiz scoring
- Quality dashboard
- Placeholder detector
- Duplicate topic checker
- Broken link checker
- Light / dark mode
- GitHub Pages ready
